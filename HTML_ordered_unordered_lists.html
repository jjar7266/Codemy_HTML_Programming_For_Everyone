Lesson Notes

In this lesson, we explored two important HTML list types: unordered lists and ordered lists. Lists are essential for organizing information on a webpage in a clean, readable format.

Unordered Lists (<ul>)

Unordered lists display items with bullet points. They are perfect for tasks, notes, or any information where order does not matter.

  • Created using the <ul> tag
  • Each item goes inside a <li> tag
  • Bullets appear automatically

Ordered Lists (<ol>)

Ordered lists display items in a specific sequence. HTML allows you to change the numbering style using the type attribute.

  • type="1" — Standard numbers (1, 2, 3)
  • type="A" — Uppercase letters (A, B, C)
  • type="a" — Lowercase letters (a, b, c)
  • type="I" — Uppercase Roman numerals (I, II, III)
  • type="i" — Lowercase Roman numerals (i, ii, iii)

Nesting Lists

You can place one list inside another to create sub‑items. This is useful for categories, shopping lists, or multi‑level outlines. Just make sure the nested list is placed inside an <li> tag to keep the structure valid.

This lesson helps build the foundation for more advanced HTML structures. Lists appear everywhere — navigation menus, documentation, forms, and even entire website layouts. Mastering them early makes everything else easier.
