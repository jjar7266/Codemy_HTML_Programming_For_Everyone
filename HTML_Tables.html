Lesson Notes

HTML tables allow us to display information in a grid of rows and columns. They are perfect for structured data such as contact lists, schedules, product information, or anything that fits into a spreadsheet-like layout.

Core Table Tags

  • <table> — wraps the entire table
  • <tr> — defines a table row
  • <th> — table header cell (bold + centered by default)
  • <td> — table data cell

Styling Tables

In this lesson, we set the table width using inline CSS: style="width:50%;". This keeps the table from stretching across the entire page. We also aligned the header row to the left using align="left".

During the lesson, we experimented with adding a border using border="1". While this works, it’s considered old‑school HTML. Modern practice is to use CSS instead: 

table, th, td {
    border: 1px solid black;
    border-collapse: collapse;
}

We’ll get into proper CSS styling later in the course, but it’s good to understand how tables can be styled both the old way and the modern way.

Why Tables Matter

Tables are foundational for organizing structured data. Even though modern layouts use CSS instead of tables for page design, tables remain essential for displaying information clearly and professionally.
