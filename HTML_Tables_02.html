Lesson Notes

In this lesson, we explored advanced table features such as colspan, rowspan, background colors, and now column width control using the <colgroup> element.

Why Your Table Looked Different

Different browsers apply different default table styles. This can cause columns to resize unpredictably. By adding a <colgroup> section, we take control of the layout and ensure consistent rendering across all browsers.

Using <colgroup> to Control Widths

The <colgroup> element allows you to define column widths before the table content loads. This ensures predictable sizing: 

<colgroup>
    <col style="width: 15%;">
    <col style="width: 35%;">
    <col style="width: 30%;">
    <col style="width: 20%;">
</colgroup>

In our example, the Name column is now wider, matching the layout seen in John's demonstration.

Other Advanced Features

  • colspan — stretches a cell across multiple columns
  • rowspan — stretches a cell across multiple rows
  • bgcolor — adds background color (old HTML method)
  • border="1" — adds a simple border (old HTML method)

Later in the course, we’ll replace these older attributes with modern CSS for cleaner and more flexible styling.
