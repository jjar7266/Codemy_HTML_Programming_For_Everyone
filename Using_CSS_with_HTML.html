Lesson Notes

In this lesson, we learned how to connect an external CSS file to an HTML document using the <link> tag. This allows us to keep our styling separate from our HTML structure, which is the modern and professional way to build websites.

Why External CSS?

  • Keeps HTML clean and readable
  • Allows one CSS file to style multiple pages
  • Makes it easier to update the look of an entire site
  • Separates content (HTML) from design (CSS)

The Link Tag

We added this line inside the <head> section: 

<link rel="stylesheet" href="style.css">

This tells the browser to load and apply the styles from the external style.css file.

Moving Away From Old HTML Styling

Earlier lessons used attributes like border="1" and bgcolor. These still work, but they are considered outdated. CSS gives us far more control and keeps our HTML clean.

Using CSS Classes

We added a class to the table: 

<table class="styled-table">

This lets us style the entire table from the CSS file without touching the HTML again.
