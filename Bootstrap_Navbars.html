Lesson Notes

In this lesson, we learned how to create a responsive Bootstrap Navbar. Navbars are one of the most common components in modern websites, and Bootstrap makes them extremely easy to build and customize.

Bootstrap Navbar Classes Used

  • navbar — the base class that activates Bootstrap's navbar styling.
  • navbar-expand-lg — the navbar expands (shows full menu) on large screens, and collapses into a hamburger menu on smaller screens.
  • navbar-dark — tells Bootstrap to use light text/icons for dark backgrounds.
  • bg-dark — applies Bootstrap’s built‑in dark background color.
  • container-fluid — makes the navbar stretch the full width of the page.
  • navbar-toggler — the button that appears on mobile screens.
  • collapse navbar-collapse — wraps the content that collapses on small screens.
  • navbar-nav — the container for your navigation links.
  • nav-link — styles each individual link.
  • d-flex — makes the search form align horizontally.

How the Navbar Works

On large screens, the navbar displays normally. On smaller screens, the links collapse into a hidden menu, and the hamburger button appears. Clicking the button toggles the menu open and closed.

Why Bootstrap Navbars Matter

Navbars are essential for website navigation. Bootstrap gives you a clean, responsive, mobile‑friendly navbar with almost no effort. You can easily add dropdowns, forms, buttons, or custom colors.
