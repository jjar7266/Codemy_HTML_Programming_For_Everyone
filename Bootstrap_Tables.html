Lesson Notes

In this lesson, we learned how to use Bootstrap’s built‑in table classes to quickly style and enhance HTML tables without writing custom CSS. Bootstrap tables are clean, responsive, and easy to customize.

Bootstrap Table Classes Used

  • table — the base Bootstrap table class that adds spacing, padding, and clean formatting.
  • table-striped — adds alternating row colors (zebra striping) for better readability.
  • table-hover — highlights rows when the mouse moves over them.
  • table-dark — used on the <thead> to create a bold, dark header row.

Row Variants

Bootstrap includes color-coded row classes to indicate meaning or highlight specific rows. In this lesson, we used: 

<tr class="table-success">

Other variants include table-primary, table-danger, table-warning, table-info, and more.

Column Width Control

We kept our <colgroup> from earlier lessons to control column widths. Bootstrap does not override these widths, so this is still the correct way to size table columns.

Why Bootstrap Tables Matter

Bootstrap tables allow you to create professional, consistent table layouts with minimal effort. They are responsive, easy to read, and perfect for dashboards, admin panels, data displays, and more.
